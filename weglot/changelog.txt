*** Weglot Translate Changelog ***
2026-09-30 - version 6.4.1
* Fix - The front end no longer shows a fatal error (Cannot unset string offsets) when the Weglot CDN refuses the API key, for example right after a wrong key was set. The site is served untranslated instead, until the key is corrected.
* Tweak - The settings cache is now refreshed automatically when the API key changes (database key replaced by the WEGLOT_API_KEY_PRIVATE constant, key rotation, wrong key corrected), so clearing the transients by hand is no longer needed.
